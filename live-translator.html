Live Spanish ⇄ English Translator

Listens to spoken Spanish, transcribes it on your device with a Whisper speech model, and shows a running English translation beside it. The audio is transcribed entirely in your browser — it never leaves the device. Only the recognized text is sent to your chosen LLM for translation, using your own API key.

API keys are set in Maat ⚙ Settings.

Audio streams to your own machine over your tailnet; transcription (Whisper large-v3) and translation (local LLM) run there. No API keys needed. The device must be connected to Tailscale. A speaker profile is built from that preacher's past sermons, so names like Ezequías, Eliseo and Namán are recognised instead of guessed.

🔒 Your API key is saved only in this browser (its localStorage) and sent directly from your device to the LLM provider — never to this website's server. Speech recognition runs fully on-device, so your audio is never uploaded anywhere. Don't enter your key on a shared computer.

Diagnostics

If something fails, tap Copy diagnostics and paste the result to Claude. The log stays on your device; anything that looks like an API key is redacted automatically.

Two background pipelines run independently: one Web Worker transcribes speech with an on-device Whisper model, a second Web Worker translates each finished sentence through your LLM. A per-sentence merge buffer joins them, so the Spanish and English panes never block one another. The first time you use it the speech model downloads (tens of MB) and is then cached for next time. Works in recent Chrome, Edge, Firefox, and Safari — including on iPad.
